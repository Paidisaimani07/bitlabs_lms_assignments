Unclosed Tag Detection Features:

  • ✅ Stack-based tag tracking
  • ✅ Detects unclosed opening tags
  • ✅ Detects mismatched closing tags
  • ✅ Ignores self-closing tags (img, br, hr, input, meta, link)
  • ✅ Ignores DOCTYPE and comments
  • ✅ Returns 0 score if any unclosed tags found
  • ✅ Provides specific error messages
