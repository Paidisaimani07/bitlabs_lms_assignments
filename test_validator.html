HTML Validator Test Cases

Test Case 1: Perfect HTML (Should PASS)

<!DOCTYPE html> <html> <body> <h1>Apple</h1> <h2>Banana</h2> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6> </body> </html>
Expected: PASS - Full marks (10/10)

Test Case 2: Unclosed H6 tag (Should FAIL)

<!DOCTYPE html> <html> <body> <h1>Apple</h1> <h2>Banana</h2> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry </body> </html>
Expected: FAIL - Unclosed H6 tag

Test Case 3: Missing BODY tag (Should FAIL)

<!DOCTYPE html> <html> <h1>Apple</h1> <h2>Banana</h2> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6> </html>
Expected: FAIL - Missing BODY tag

Test Case 4: Multiple unclosed tags (Should FAIL)

<html> <body> <h1>Apple</h1> <h2>Banana <h3>Orange</h3> <h4>Grape <h5>Mango</h5> <h6>Cherry</h6>
Expected: FAIL - Multiple unclosed tags

Test Case 5: Missing DOCTYPE (Should PASS with partial marks)

<html> <body> <h1>Apple</h1> <h2>Banana</h2> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6> </body> </html>
Expected: PASS - 9/10 marks (missing DOCTYPE)

Test Case 6: Only headings, no structure (Should FAIL)

<h1>Apple</h1> <h2>Banana</h2> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6>
Expected: FAIL - Missing HTML structure

Test Case 7: Empty heading (Should FAIL)
