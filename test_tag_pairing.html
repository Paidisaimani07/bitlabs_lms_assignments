Expected: PASS - All tags properly paired

Expected: FAIL - Unclosed H6 tag

Test 3: Mismatched Tag Order (FAIL)

<!DOCTYPE html> <html> <body> <h1>Apple</h2> <h2>Banana</h1> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6> </body> </html>
Expected: FAIL - Mismatched H1/H2 tags

Test 4: Multiple Unclosed Tags (FAIL)

<!DOCTYPE html> <html> <body> <h1>Apple</h1> <h2>Banana <h3>Orange</h3> <h4>Grape <h5>Mango</h5> <h6>Cherry</h6> </body> </html>
Expected: FAIL - Unclosed H2 and H4 tags

Test 5: Unexpected Closing Tag (FAIL)

<!DOCTYPE html> <html> <body> <h1>Apple</h1> </h2> <h2>Banana</h2> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6> </body> </html>
Expected: FAIL - Unexpected closing H2 tag

Test 6: Nested Tags Wrong Order (FAIL)

<!DOCTYPE html> <html> <body> <div> <h1>Apple</h1> <h2>Banana</h2> </div> </body> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6> </html>
Expected: FAIL - Wrong closing order (DIV before BODY)

Test 7: Self-Closing Tags (PASS)

<!DOCTYPE html> <html> <head></head> <body> <h1>Apple</h1> <img src="test.jpg" alt="test" /> <br /> <h2>Banana</h2> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6> <hr /> </body> </html>
Expected: PASS - Self-closing tags ignored

Test 8: Empty Tags (FAIL)

<!DOCTYPE html> <html> <body> <h1></h1> <h2>Banana</h2> <h3></h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6> </body> </html>
Expected: FAIL - Empty H1 and H3 tags

Test 9: Deep Nesting Error (FAIL)

<!DOCTYPE html> <html> <body> <div> <section> <article> <h1>Apple</h1> <h2>Banana</h2> </section> </article> <h3>Orange</h3> <h4>Grape</h4> <h5>Mango</h5> <h6>Cherry</h6> </body> </html>
Expected: FAIL - Wrong nesting order (SECTION/ARTICLE)
